학생회원 관리 안내

글을 쓰고 저장을 누르면 1~2분 뒤 사이트와 AI용 파일(llms.txt, JSON)에 자동 반영돼요. 코딩은 필요 없어요.

방법 A. 이메일 초대로 쓰기 (GitHub 계정 없어도 됨, 추천)

  1. 학생회장이 Pages CMS에서 저장소 echoalpa/hyu-ie-info를 열고, 설정의 Collaborators에서 학생회원 이메일을 초대해요.
  2. 초대받은 사람은 메일의 링크로 들어가 바로 글을 쓸 수 있어요.

방법 B. 이 사이트의 관리 화면 쓰기 (GitHub 계정 필요)

  1. 학생회장이 GitHub 저장소 Settings → Collaborators에서 학생회원의 GitHub 아이디를 초대해요.
  2. 학생회원은 GitHub에서 토큰 만들기: Repository access는 hyu-ie-info만, Permissions에서 Contents: Read and write를 고르고 생성.
  3. 관리 화면에서 액세스 토큰으로 로그인을 누르고 토큰을 붙여 넣어요. 한 번 로그인하면 그 브라우저에선 계속 유지돼요.

글 쓰는 요령 (AI가 잘 읽게)

  • 한 줄 요약을 꼭 채워주세요. AI가 가장 먼저 읽어요. "누가·언제·어디서·무엇을"을 넣으면 좋아요.
  • 날짜·시간·장소는 본문 말고 전용 칸에 넣어주세요. 그래야 "이번 주 행사 뭐 있어?"에 정확히 답해요.
  • FAQ 질문은 학생이 실제로 물어볼 말투로 적어요. 예: "졸업하려면 인턴 꼭 해야 해요?"
  • 확실하지 않은 정보는 쓰지 말고, 근거 링크를 같이 넣어주세요. 정보를 다시 확인했으면 확인한 날짜를 고쳐주세요.
  • 쓰다 만 글은 공개를 꺼두면 사이트에 안 보여요.
  • [예시]로 시작하는 비공개 글을 복제해서 쓰면 편해요.
  • 개인 연락처·학번 등 개인정보는 본인 동의 없이 올리지 마세요. 공개 사이트라 누구나 볼 수 있어요.
